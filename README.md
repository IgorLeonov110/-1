# Weather Diary (Дневник погоды)

## Автор
 Игорь Леонов

## Краткое описание программы
Weather Diary — это графическое приложение (GUI) для ведения дневника погоды. Программа позволяет:
- Добавлять записи о погоде с указанием даты, температуры, описания и наличия осадков.
- Просматривать все добавленные записи в виде таблицы.
- Фильтровать записи по дате и температуре (например, показывать записи с температурой выше +10°C).
- Сохранять все записи в файл JSON и загружать их обратно.
- Удалять выбранные записи.

Приложение проверяет корректность ввода данных (формат даты, числовое значение температуры, непустое описание).

## Как запустить приложение

### Требования
- Установленный Python 3.6 или выше
- Стандартные библиотеки Python (tkinter, json, datetime, os) — дополнительная установка не требуется

### Запуск
1. Сохраните код программы в файл `weather_diary.py`
2. Откройте терминал (командную строку) в папке с файлом
3. Выполните команду:
   ```bash
   python weather_diary.py

Примеры использования
Пример 1: Добавление новой записи
В поле "Date (YYYY-MM-DD)" введите 2025-05-18

В поле "Temperature (°C)" введите 22.5

В поле "Description" введите Солнечно, легкий ветер

Отметьте чекбокс "Precipitation" (если были осадки) или оставьте пустым

Нажмите кнопку "Add Record"

Пример 2: Фильтрация записей
Чтобы показать записи только за 2025-05-18: в поле "Filter by Date" введите 2025-05-18 и нажмите "Apply Filters"

Чтобы показать записи с температурой выше +10°C: в поле "Filter by Temperature >:" введите 10 и нажмите "Apply Filters"

Можно применять оба фильтра одновременно

Пример 3: Сохранение и загрузка
Нажмите "Save to JSON" — записи сохранятся в файл weather_diary.json

Нажмите "Load from JSON" — загрузят сохранённые записи из файла

Пример 4: Удаление записи
Выберите запись в таблице (щёлкните по ней)

Нажмите "Delete Selected" и подтвердите удаление

Структура JSON файла
json
[
    {
        "date": "2025-05-18",
        "temperature": 22.5,
        "description": "Солнечно, легкий ветер",
        "precipitation": "No"
    }
]
